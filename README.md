# 流量管家（TrafficBar）

流量管家是一款 macOS 菜单栏工具，用来查看各个应用的网络流量。

## 功能

- 查看下载、上传和当前网速。
- 按应用查看流量排行。
- 区分代理、直连和本地流量。
- 支持小时、今天、本周和本月统计。
- 使用应用自己的 macOS 图标。

## 使用方法

1. 打开“流量管家”。
2. 点击菜单栏中的上下行箭头图标。
3. 在弹窗中选择时间范围和流量类型。
4. 在应用列表中查看各应用的下载、上传和连接类型。

首次打开时，如果询问是否自动检查更新，可以选择“自动检查”或“不检查”。更新只来自流量管家自己的 GitHub 仓库。

## 安装

从 [Releases](https://github.com/Crossng/Mac-TrafficBar/releases) 下载最新版本的 DMG 文件，打开后将“流量管家”拖入“应用程序”文件夹。

系统要求：macOS 13 或更高版本。

## 数据位置

流量记录只保存在本机：

`~/Library/Application Support/TrafficBar/`

删除这个文件夹会清除历史流量记录。
