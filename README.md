# 流量管家

流量管家是一款原生 macOS 菜单栏工具，用于在本机查看网络速度、流量汇总和应用流量排行。

## 主要功能

- 显示当前下载与上传速度
- 按小时、今天、本周和本月查看流量
- 区分代理、直连和本地流量
- 展示各应用的下载、上传和路径构成
- 数据仅保存在本机
- 支持应用内检查更新

## 安装

1. 从 [Releases](https://github.com/Crossng/Mac-TrafficBar/releases) 下载最新的 `TrafficBar-macos-arm64.dmg`。
2. 打开安装镜像，将“流量管家”拖入“应用程序”。
3. 启动后，点击菜单栏中的上下箭头图标查看流量。

需要 macOS 13 或更高版本，当前发布包适用于 Apple 芯片 Mac。

## 使用

- 使用上方两组筛选器切换统计时间和流量类型。
- 点击底部刷新按钮立即重新采样。
- 点击文件夹按钮打开本地数据目录。
- 点击下载图标手动检查新版本。

流量管家不会上传流量记录，也不会安装系统扩展。显示结果来自 macOS 本机网络统计，可能与运营商账单或路由器统计存在少量差异。
