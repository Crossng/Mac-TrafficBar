# 流量管家（TrafficBar）

流量管家是一款 macOS 菜单栏工具，用来查看各个应用的网络流量。

## 可以查看

- 下载、上传和当前网速
- 各应用的流量排行
- 代理、直连和本地流量
- 小时、今天、本周和本月的统计
- 各应用自己的 macOS 图标

## 使用方法

1. 打开“流量管家”。
2. 点击菜单栏中的上下行箭头图标。
3. 选择时间范围和流量类型。
4. 在列表中查看各应用的流量明细。

首次打开时，应用会询问是否自动检查更新。不需要自动更新时，选择“不检查”即可；之后也可以从菜单栏中手动检查更新。

## 安装

从[下载页](https://github.com/Crossng/Mac-TrafficBar/releases)获取最新版本，打开 DMG 后将“流量管家”拖入“应用程序”文件夹。

系统要求：macOS 13 或更高版本。

## 数据与隐私

流量记录只保存在本机，不需要注册账号：

`~/Library/Application Support/TrafficBar/`

删除这个文件夹会清除历史流量记录。
